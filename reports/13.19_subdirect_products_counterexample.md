# Problem 13.19 (Yu. M. Gorchakov) — a counterexample: Q/H need not be regular

**Problem 13.19.** Suppose that a group Q and its normal subgroup H are subgroups of the direct product
G₁ × ⋯ × G_n such that for each i the projections of both Q and H onto G_i coincide with G_i. If Q/H is a
p-group, is Q/H a regular p-group?

**Answer: No.** There are finite 2-groups Q (of order 2⁹, class 2) with H ⊴ Q and n = 3 such that
Q/H ≅ D₈ (dihedral of order 8), which is not regular (a regular 2-group is abelian).

## Reformulation
If Q ≤ G₁ × ⋯ × G_n, let N_i = Q ∩ ker(π_i). Then ∩N_i = 1, and "H projects onto G_i" means HN_i = Q.
Conversely, given a group Q with normal subgroups N₁,…,N_n with ∩N_i = 1 and a normal subgroup H with
HN_i = Q for all i, put G_i := Q/N_i; then Q embeds in ∏G_i, both Q and H project onto each G_i, and the
quotient Q/H is unchanged. (One easily shows γ_n(Q) ≤ H(N₁∩⋯∩N_n) = H, so Q/H has class ≤ n − 1; in
particular Q/H is abelian for n = 2, and class ≤ 2 for n = 3.)

## The construction (n = 3, p = 2)
Let V = F₂² with the alternating form γ(v,w) = v₁w₂ + v₂w₁ and the bilinear map c₁(v,w) = v₁w₂
(so c₁(v,v) = v₁v₂ and c₁(v,w) + c₁(w,v) = γ(v,w)). Let A = F₂³ with basis u₁₂, u₁₃, u₂₃, and set
  w₁₁ = u₁₂, w₂₂ = u₂₃, w₃₃ = u₁₃, w_{ij} = w_{ji} = u_{ij} (i < j).
On the set Q = V³ × A define
  (x, a)(y, b) = (x + y, a + b + c(x, y)),  c(x, y) = Σ_i c₁(x_i, y_i) w_{ii} + Σ_{i<j} γ(x_i, y_j) w_{ij},
where x = (x₁,x₂,x₃) with x_i ∈ V. Since c is bilinear, this is a group of order 2⁹ (a central extension of
V³ by A; A = {(0,a)} is central). Its commutator and squaring maps are
  [(x,a),(y,b)] = (0, β(x,y)),  β(x,y) = c(x,y) + c(y,x) = Σ_i γ(x_i,y_i) w_{ii} + Σ_{i≠j} γ(x_i,y_j) w_{ij},
  (x,a)² = (0, q(x)),  q(x) = Σ_i q₁(x_i) w_{ii} + Σ_{i<j} γ(x_i,x_j) w_{ij},  q₁(v) = v₁v₂.
Equivalently, Q is generated by involutions e_i, f_i (i = 1,2,3; the standard basis of the i-th copy of V)
and central involutions u₁₂, u₁₃, u₂₃ with
  [e_i, f_i] = w_{ii},  [e_i, f_j] = [f_i, e_j] = u_{ij} (i ≠ j),  [e_i, e_j] = [f_i, f_j] = 1.
Define
  N_i := {(x, a) : x_j = 0 for j ≠ i, a ∈ ⟨u_{ij}, u_{ik}⟩}   ({i,j,k} = {1,2,3}),
  Ĥ := {(x, a) : x₁ + x₂ + x₃ = 0},  A₀ := ⟨u₁₂ + u₁₃, u₁₃ + u₂₃⟩ ≤ A.

**Claims.**
1. N_i is a subgroup of order 16 (closed since c(x,y) ∈ ⟨w_{ii}⟩ for x, y in the i-th block), normal in Q
   (Q has class 2 and [Q, N_i] ⊆ ⟨w_{1i}, w_{2i}, w_{3i}⟩ = ⟨u_{ij}, u_{ik}⟩ ⊆ N_i); N_i ∩ N_j = ⟨u_{ij}⟩ (i ≠ j)
   and N₁ ∩ N₂ ∩ N₃ = 1.
2. Ĥ is a subgroup of order 2⁷ containing A, and Ĥ/A₀ is elementary abelian: for x, y with Σx_i = Σy_i = 0
   one has β(x,y) ≡ γ(Σx_i, Σy_i)·u ≡ 0 and q(x) ≡ q₁(Σx_i)·u ≡ 0 modulo A₀ (here u denotes the common
   image of the u_{ij} in A/A₀ ≅ C₂), because modulo A₀ all w_{ij} become equal.
3. Ĥ/A₀ is central in Q/A₀ (same computation: β(x,y) ≡ γ(Σx_i, Σy_i)·u = 0 when Σy_i = 0), and
   Q/Ĥ ≅ V³/ker(s) ≅ V (s = summation map). Choose a complement H/A₀ of A/A₀ in the elementary abelian
   group Ĥ/A₀ = (A/A₀) × (Ĥ/A) (any such complement H is a subgroup of Q of order 2⁶ with H ∩ A = A₀;
   it is normal in Q because Ĥ/A₀ is central in Q/A₀).
4. HN_i = Q: indeed (H/A₀) ∩ (N_iA₀/A₀) = 1 (an element of H/A₀ has Σx_i = 0, an element of N_iA₀/A₀ has
   x supported in block i, so x = 0, and then it lies in A/A₀ ∩ H/A₀ = 1), so |HN_i| = 2⁶·16/4 = 2⁸ … more
   precisely |H N_i| = |H||N_i|/|H ∩ N_i| and H ∩ N_i ⊆ H ∩ N_iA ∩ … = A₀ ∩ N_i = ⟨u_{ij}+u_{ik}⟩ of order 2,
   giving |HN_i| = 64·16/2 = 512 = |Q|.
5. Q/H has order 8 and is non-abelian: Q/H ≅ (Q/A₀)/(H/A₀) is a central extension of Q/Ĥ ≅ V by
   Ĥ/H ≅ A/A₀ ≅ C₂ whose commutator form is induced by β modulo A₀, i.e. by γ(Σx_i, Σy_i) ≠ 0. With
   q₁ hyperbolic (v₁v₂) the squaring map on V is isotropic, so Q/H ≅ D₈; (with q₁ = v₁²+v₁v₂+v₂² one gets Q₈).

Hence, with G_i := Q/N_i (groups of order 32), Q embeds as a subdirect product in G₁ × G₂ × G₃, H is a
normal subgroup of Q projecting onto each G_i, and Q/H ≅ D₈ is a non-regular 2-group. ∎
