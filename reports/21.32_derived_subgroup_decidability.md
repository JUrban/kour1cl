# Problem 21.32 (P. J. Cameron) — "Is G the derived subgroup of some finite group?" is decidable

**Problem 21.32.** Is the following problem decidable, and if so, what is its complexity? Given a finite
group G, is there a finite group H such that the derived subgroup of H is isomorphic to G?

**Answer.** Yes, it is decidable. More precisely:

> **Theorem A.** Let G be a finite group, let e = 2·exp(Z(G)), and let m = ⌈log₂|G|⌉. If G ≅ H′ for some
> finite group H, then G ≅ (H*)′ for a finite group H* with
>
>   |H*| ≤ |Aut(G)| · |Z(G)|² · e^{2m}.
>
> Consequently the problem is decidable (search all groups of order at most this bound), and the bound is
> quasi-polynomial in |G| (since |Aut(G)| ≤ |G|^{log₂|G|}); so the problem lies in NTIME(n^{O(log n)}) for
> input size n = |G| (a witness H* of quasi-polynomial size, on which "H*′ ≅ G" is checked in quasi-polynomial
> time).

> **Theorem B (necessary condition; sufficient when Z(G)=1).** If G ≅ H′ for a finite group H, then there is a
> subgroup Q with Inn(G) ≤ Q ≤ Aut(G) and Q′ = Inn(G). If Z(G) = 1 the converse holds: G ≅ H′ for some finite
> H if and only if Inn(G) ≅ G is the derived subgroup of some subgroup Q of Aut(G) containing Inn(G).
> In particular, for centerless G the problem reduces to a finite computation inside Aut(G).

Examples: S₃ and D₈ are not derived subgroups of any finite group (Theorem B: Aut(S₃)=S₃ has derived
subgroup C₃ ≠ Inn(S₃); Aut(D₈) = D₈ has no subgroup Q ⊇ Inn(D₈) ≅ C₂² with Q′ = C₂²), while Q₈ = SL(2,3)′
and A₄ = S₄′. (These examples are confirmed by brute force in `work/p21_32/`.)

## 1. Set-up and the basic structure

Throughout, H is a finite group with H′ = G (we identify G with the subgroup H′ ≤ H). Put

  K := C_H(G),  Z := Z(G).

(1.1) H/G is abelian (as G = H′).
(1.2) K ⊴ H and H/K embeds in Aut(G) (conjugation action). Its image Q := H/K contains Inn(G) = GK/K.
(1.3) K ∩ G = C_G(G) = Z.
(1.4) [H, K] ≤ H′ ∩ K = G ∩ K = Z (using K ⊴ H). In particular K′ ≤ Z, so K is nilpotent of class ≤ 2, and
      K/Z is central in H/Z. Also K ≤ C_H(Z) since K centralises G ⊇ Z.
(1.5) Commutator calculus: for h,h′ ∈ H and k,k′ ∈ K,
        [hk, h′k′] = [h,h′k′]^k [k,h′k′] = ([h,k′][h,h′]^{k′})^k · [k,k′][k,h′]^{k′}.
      The factors [h,k′], [k,h′], [k,k′] lie in Z ≤ K, and Z is centralised by K. Hence, for any subgroup
      H₁ ≤ H with H = H₁K, one has
        G = H′ = H₁′ · [H₁,K] · K′,                                             (∗)
      where the right-hand side is a subgroup because [H₁,K]K′ ≤ Z ≤ G ≤ H₁ normalises H₁′ and H₁′ ≤ G
      is centralised by K.

**Proof of Theorem B.** Put H̃ = H/Z, K̃ = K/Z, G̃ = G/Z. By (1.4) K̃ is central in H̃, and H̃/K̃ ≅ H/K = Q.
Since H′ = G we get H̃′ = G̃, and G̃ ∩ K̃ = (G ∩ K)/Z = 1 by (1.3). The projection π: H̃ → Q maps H̃′ onto
Q′ with kernel H̃′ ∩ K̃ = G̃ ∩ K̃ = 1, so π restricts to an isomorphism G̃ = H̃′ → Q′; but π(G̃) = π(GK/K) is
precisely the group Inn(G) of inner automorphisms. Hence Q′ = Inn(G).
If Z(G) = 1 then K ∩ G = 1, [H,K] = 1, so K ≤ Z(H) and H′ ∩ K = 1; hence H′ ≅ (H/K)′ = Q′ = Inn(G) ≅ G is
realised by the subgroup Q ≤ Aut(G) itself (take H := Q). ∎

## 2. Reduction 1: bounded rank

Since G = H′ is generated by commutators [a,b] (a,b ∈ H) and every generating set of a group of order |G|
contains a generating subset of size ≤ log₂|G|, we can choose a₁,b₁,…,a_m,b_m ∈ H, m ≤ log₂|G|, with
G = ⟨[a_i,b_i] : i ≤ m⟩. Let H₀ := ⟨G, a₁,b₁,…,a_m,b_m⟩. Then H₀′ ⊇ ⟨[a_i,b_i]⟩ = G and H₀′ ≤ H′ = G, so
H₀′ = G. Moreover H₀/G is an abelian group generated by the 2m images of the a_i, b_i.
Replacing H by H₀ we may and do assume:

  (2.1) H′ = G and H/G is abelian, generated by 2m ≤ 2log₂|G| elements.

Then K/Z ≅ KG/G ≤ H/G is abelian and generated by ≤ 2m elements (subgroups of a d-generated finite abelian
group are d-generated).

## 3. Reduction 2: a large central subgroup

Let e := 2·exp(Z). For k,k′ ∈ K we have [k,k′] ∈ K′ ≤ Z (1.4), and K has class ≤ 2, so
(kk′)^e = k^e k′^e [k′,k]^{e(e−1)/2}; since e(e−1)/2 is a multiple of exp(Z) (e is even), the last factor is
trivial. Hence k ↦ k^e is an endomorphism of K and C := K^e = {k^e : k ∈ K} is a characteristic subgroup of K,
so C ⊴ H. For h ∈ H and k ∈ K, [h,k] ∈ Z is centralised by k, so [h,k^e] = [h,k]^e = 1. Thus

  (3.1) C ≤ Z(H).

Furthermore K/C has exponent dividing e, and K/CZ is an abelian group (a quotient of K/Z) generated by ≤ 2m
elements of exponent dividing e, so |K : CZ| ≤ e^{2m} and

  (3.2) |H/C| = |H:K| · |K:CZ| · |CZ:C| ≤ |Aut(G)| · e^{2m} · |Z|.

## 4. Reduction 3: replacing the central subgroup C by C ∩ G (Baer sums)

Put H̄ := H/C and C₀ := C ∩ G = C ∩ Z (a subgroup of Z, as C ≤ K). Since C is central, H is a central
extension 1 → C → H → H̄ → 1 with class ξ ∈ H²(H̄, C) (trivial action). Recall two standard facts for a
central extension 1 → M → E → Q → 1 with class η:

 (F1) (Hopf) The 5-term exact sequence H₂(E) → H₂(Q) → M → E^{ab} → Q^{ab} → 0 shows that the image of the
      "Hopf map" h_η : H₂(Q) → M equals M ∩ E′.
 (F2) (Universal coefficients) 0 → Ext(Q^{ab}, M) → H²(Q, M) → Hom(H₂(Q), M) → 0 is exact, where the second
      map sends η to h_η; it is natural in M.

By (F1), h_ξ has image C ∩ H′ = C ∩ G = C₀. Let ι : C₀ ↪ C. By (F2) applied to the coefficient group C₀ there
is ξ* ∈ H²(H̄, C₀) with h_{ξ*} = h_ξ (viewed as a map H₂(H̄) → C₀). Let H* be the central extension of H̄ by
C₀ with class ξ*; then |H*| = |H̄| · |C₀|. By naturality h_{ι_*ξ*} = ι∘h_{ξ*} = h_ξ, so ξ − ι_*ξ* has trivial
Hopf map, i.e. lies in Ext(H̄^{ab}, C) ⊆ H²(H̄, C); let A be a central extension of H̄ by C with this class.
By (F1), A′ ∩ C = 1, so A′ → H̄′ is an isomorphism.

The extension ι_*ξ* is the pushout E₁ := (H* × C)/{(c, c^{-1}) : c ∈ C₀} = H* ∘_{C₀} C (central product), and
E₁′ = (H*)′ because C is central in E₁ and E₁ = H*·C.

Now ξ = ι_*ξ* + (ξ − ι_*ξ*) is a Baer sum: H ≅ (E₁ ×_{H̄} A)/Δ, where E₁ ×_{H̄} A is the fibre product over H̄
(a central extension of H̄ by C × C) and Δ = {(c, c^{-1}) : c ∈ C}. Let F := E₁ ×_{H̄} A.

Claim: F′ = E₁′ ×_{H̄′} A′ ≅ E₁′.
Indeed F′ ⊆ E₁′ ×_{H̄′} A′ := {(x,y) ∈ E₁′ × A′ : x and y have the same image in H̄′}. By naturality of the
Hopf map under the two projections F → E₁, F → A, the Hopf map of F is (h_{ι_*ξ*}, h_{ξ−ι_*ξ*}) = (h_ξ, 0),
whose image is C₀ × 1; by (F1) F′ ∩ (C × C) = C₀ × 1. As F′ maps onto H̄′, |F′| = |H̄′| · |C₀|. On the other
hand |E₁′ ×_{H̄′} A′| = Σ_{z ∈ H̄′} |E₁′ ∩ π^{-1}(z)| · |A′ ∩ π^{-1}(z)| = |H̄′| · |E₁′ ∩ C| · |A′ ∩ C| =
|H̄′| · |C₀| · 1. Hence F′ = E₁′ ×_{H̄′} A′, and projection to the first coordinate is an isomorphism
E₁′ ×_{H̄′} A′ → E₁′ (injective because A′ ∩ C = 1 forces y to be determined by the image of x; surjective
because A′ → H̄′ is onto). This proves the claim.

Finally F′ ∩ Δ = {(c, c^{-1}) : c ∈ C₀, c^{-1} = 1} = 1, so
  H′ = (F/Δ)′ = F′Δ/Δ ≅ F′ ≅ E₁′ = (H*)′.
Therefore (H*)′ ≅ H′ = G, and by (3.2)

  |H*| = |H̄| · |C₀| ≤ |Aut(G)| · e^{2m} · |Z| · |Z|.

This proves Theorem A. ∎

## 5. Remarks on complexity

* The witness H* of Theorem A has order at most |Aut(G)| |Z(G)|² (2 exp Z(G))^{2⌈log₂|G|⌉}. With
  |Aut(G)| ≤ |G|^{log₂|G|} this is |G|^{O(log|G|)}; the property "(H*)′ ≅ G" is verifiable in time
  quasi-polynomial in |G| (group isomorphism for groups of order N is decidable in time N^{O(log N)}). Hence
  the decision problem is in nondeterministic quasi-polynomial time. (The naive deterministic algorithm —
  enumerate all groups up to the bound — is of course far worse.)
* For centerless G, Theorem B gives a much better algorithm: compute A = Aut(G), I = Inn(G), and decide whether
  some subgroup Q with I ≤ Q ≤ A has Q′ = I. Since Q′ = I forces Q/I abelian, one only needs subgroups of
  A/I that are abelian; e.g. it suffices to test the subgroups ⟨I, q₁,…,q_r⟩ with r ≤ 2⌈log₂|G|⌉.
* The necessary condition of Theorem B is not sufficient in general when Z(G) ≠ 1 is possible a priori; the
  brute-force cross-check in `work/p21_32/` compares the criterion with actual derived subgroups for all groups
  G of order ≤ 32 (see the log for the outcome).
