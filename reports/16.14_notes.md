# Problem 16.14 (Berkovich) — partial result: the class-2 case via Chevalley–Warning

**Problem.** G a finite 2-group with Ω₁(G) ≤ Z(G). Is rank(G/G²) ≤ 2·rank(Z(G))?
(Here rank(G/G²) = d(G) = dim G/Φ(G) and rank(Z(G)) = dim Ω₁(Z(G)) = dim Ω₁(G) =: r.)

**Status.** Verified for all 2-groups of order ≤ 2⁸ (`work/p16_14`). A counterexample must have
r ≥ 3, d ≥ 7 and order ≥ 2¹⁰ (see below), so it is out of reach of the SmallGroups library.
Proved below for groups of class ≤ 2 with G² ≤ Z(G) (this includes all class-2 groups whose derived
subgroup has exponent 2). The bound is sharp: Q₈^r has r = d/2.

**Theorem.** Let G be a 2-group of class ≤ 2 with G² ≤ Z(G) and Ω₁(G) ≤ Z(G). Then d(G) ≤ 2·rank Z(G).

*Proof.* Put Z = Z(G), r = rank Z = dim(Z/Z²) (Z is abelian). Since G has class ≤ 2, for g,h ∈ G we have
(gh)² = g²h²[h,g] with [h,g] ∈ G′ ≤ Z. Hence the map Q : G → Z/Z², g ↦ g²Z², satisfies
Q(gh) = Q(g)Q(h)·[h,g]Z², Q(gz) = Q(g) for z ∈ Z, and Q(g²) = 1. So Q factors through the
F₂-vector space V := G/(ZG²) and is a quadratic map q : V → W := Z/Z² ≅ F₂^r whose polar form is the
commutator pairing. (Write q = (q₁,…,q_r) in coordinates: r quadratic forms on V.)
"Ω₁(G) ≤ Z" says: g² = 1 ⇒ g ∈ Z. If v ∈ V \ {0} had q(v) = 0, then for a preimage g ∉ ZG² of v we would
have g² = z² for some z ∈ Z, so (gz⁻¹)² = g²z⁻² = 1 (z central), hence gz⁻¹ ∈ Ω₁(G) ≤ Z and g ∈ Z, a
contradiction. So the r quadratic forms q₁,…,q_r have no common non-trivial zero on V. By the
Chevalley–Warning theorem (Σ deg q_i = 2r < dim V would force a non-trivial common zero), n := dim V ≤ 2r.
Let W′ := span(q(V)) ⊆ W, r′ := dim W′ ≤ r; the same argument with the r′ forms spanning W′ gives n ≤ 2r′.
Finally Φ(G) = G²G′ ≤ Z (as G² ≤ Z and G′ ≤ Z), Z² ≤ G² ≤ Φ(G), and Φ(G)Z²/Z² ⊇ W′, so
  d(G) = dim G/Φ(G) = dim G/ZG² + dim ZG²/Φ(G) = n + dim Z/Φ(G) ≤ n + dim(Z/Z²) − dim W′ ≤ 2r′ + r − r′ ≤ 2r.  ∎

**Remark (why the library cannot contain a counterexample).** If d(G) > 2r then, since Ω₁(G) ≤ Φ(G)? — not
needed: |G| ≥ |G/Φ(G)|·|Ω₁(G)| only when Ω₁(G) ≤ Φ(G); in general |G| ≥ 2^d·2^{r−s} where s = dim of
Ω₁(G)Φ(G)/Φ(G) ≤ r. The groups with r ≤ 2 are covered by Konvisser's classification of 2-groups with at
most three involutions (all have d ≤ 4). Thus a counterexample needs r ≥ 3, d ≥ 7, |G| ≥ 2^{7}·2^{3−s}; the
sweep of all groups of order ≤ 2⁸ found none.
