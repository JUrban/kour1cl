# Problem 16.14 (Berkovich) — partial results

**Problem.** G a finite 2-group with Ω₁(G) ≤ Z(G). Is rank(G/G²) ≤ 2·rank(Z(G))?

Notation. For such G put E := Ω₁(G) (elementary abelian, central, generated by all involutions),
r := rank Z(G) = rank E (Ω₁(Z(G)) = E), d := d(G) = rank(G/G²) = dim G/Φ(G) (for a 2-group Φ(G) = G²).
The bound d ≤ 2r is sharp: Q₈^r has d = 2r, r = rank Z. Call G *extremal* if d(G) = 2r(G).

**Status.**
* Theorem A: the answer is yes for class ≤ 2 with G² ≤ Z(G) (Chevalley–Warning).
* Theorem B: a counterexample of minimal order has d = 2r + 1 and a rigid structure (below).
* Theorem C: there is no counterexample of order ≤ 2¹⁰ (unconditionally), and none of order 2¹¹ or 2¹² with r ≥ 3. For r = 2 (three involutions) the remaining
  orders ≥ 2¹¹ are covered only by the literature (Konvisser 1973 / Janko 2005), see below. The exclusion
  combines Theorem B with an exhaustive analysis of the possible quotients H = G/E in the SmallGroups library and
  a cohomological criterion (Theorem B(v),(vii)).
* Numerically: d ≤ 2r for all 2-groups of order ≤ 2⁸ (direct sweep, `work/p16_14/check.g`).

---
## Theorem A (class ≤ 2, G² ≤ Z(G))
Let G be a 2-group of class ≤ 2 with G² ≤ Z(G) and Ω₁(G) ≤ Z(G). Then d(G) ≤ 2·rank Z(G).

*Proof.* Put Z = Z(G), r = rank Z = dim(Z/Z²). Since G has class ≤ 2, (gh)² = g²h²[h,g] with [h,g] ∈ G′ ≤ Z.
Hence Q : G → Z/Z², g ↦ g²Z², satisfies Q(gh) = Q(g)Q(h)·[h,g]Z², Q(gz) = Q(g) for z ∈ Z, Q(g²) = 1. So Q
factors through the F₂-space V := G/(ZG²) and is a quadratic map q : V → W := Z/Z² ≅ F₂^r whose polar form is
the commutator pairing; in coordinates q = (q₁,…,q_r), r quadratic forms on V.
If v ∈ V∖{0} had q(v) = 0, a preimage g ∉ ZG² of v would satisfy g² = z² with z ∈ Z, so (gz⁻¹)² = 1, hence
gz⁻¹ ∈ Ω₁(G) ≤ Z and g ∈ Z, a contradiction. So q₁,…,q_r have no common non-trivial zero; by Chevalley–Warning
n := dim V ≤ 2r. With W′ := span q(V), r′ := dim W′ ≤ r, the same argument gives n ≤ 2r′. Finally
Φ(G) = G²G′ ≤ Z, Z² ≤ G² ≤ Φ(G), and Φ(G)Z²/Z² ⊇ W′, so
d(G) = dim G/ZG² + dim ZG²/Φ(G) = n + dim Z/Φ(G) ≤ n + (r − r′) ≤ 2r′ + r − r′ ≤ 2r. ∎

Remark. If Φ(G) is central and elementary abelian (i.e. G has p-class ≤ 2), then G² ≤ Φ(G) ≤ Z(G) and
G′ ≤ Φ(G) ≤ Z(G), so Theorem A applies.

## Theorem B (structure of a minimal counterexample)
Let G be a counterexample of minimal order, i.e. Ω₁(G) ≤ Z(G), d(G) > 2r(G), and d(K) ≤ 2r(K) for every
2-group K of smaller order with Ω₁(K) ≤ Z(K) (r(K) := rank Ω₁(K)). Write E = Ω₁(G), r = r(G), H := G/E. Then:

(i) d(G) = 2r + 1, and every maximal subgroup M of G satisfies Ω₁(M) = E, d(M) = 2r = 2r(M).
(ii) E ≤ Φ(G); hence d(H) = d(G) = 2r + 1.
(iii) Φ(M) = Φ(G) for every maximal subgroup M; consequently every maximal subgroup M̄ of H has Φ(M̄) = Φ(H).
(iv) Every g ∈ G∖E has order 2·|gE|; every involution of H lifts to elements of order 4 of G, every element of
     order 4 of H to elements of order 8, etc.
(v) For every elementary abelian subgroup A ≤ H the squaring map induces a quadratic map q_A : A → E without
    non-trivial zeros; hence rank A ≤ 2r (Chevalley–Warning). In particular the 2-rank of H is ≤ 2r.
(vi) Every subgroup Q ≤ H with trivial Schur multiplier is abelian (e.g. H contains no generalised quaternion
     subgroup).
(vii) r ≥ 2, |Φ(G)| ≥ 2|E|, and |G| ≥ 2^{3r+2}. In particular |G| ≥ 2⁸.

*Proof.* Subgroups inherit the hypothesis: for K ≤ G, Ω₁(K) ≤ E ∩ K ≤ Z(G) ∩ K ≤ Z(K) and r(K) ≤ r. For a maximal
subgroup M, M ⊇ Φ(G) and M/Φ(G) is an elementary abelian quotient of M of rank d − 1, so d(M) ≥ d(G) − 1. By
minimality d(M) ≤ 2r(M) ≤ 2r, hence d(G) ≤ 2r + 1; as d(G) > 2r we get d(G) = 2r + 1, d(M) = 2r, r(M) = r, so
Ω₁(M) = E. This is (i).
(ii): if t ∈ E∖Φ(G), pick a maximal M with t ∉ M; then G = M × ⟨t⟩ (t central, M ∩ ⟨t⟩ = 1), so
Ω₁(G) = Ω₁(M) × ⟨t⟩, r(M) = r − 1, and d(M) = d(G) − 1 = 2r = 2r(M) + 2, contradicting minimality applied to M.
Since E ≤ Φ(G) we have G/Φ(G) ≅ H/Φ(H), d(H) = d(G).
(iii): Φ(M) is characteristic in M ⊴ G, so Φ(M) ≤ Φ(G) (a standard fact for normal subgroups), and
|M : Φ(M)| = 2^{2r} = |G : Φ(G)|/2 = |M : Φ(G)|, so Φ(M) = Φ(G). Passing to H: Φ(M/E) = Φ(M)E/E = Φ(G)/E = Φ(H).
(iv): let g ∉ E and |gE| = 2^k (k ≥ 1). Then g^{2^k} ∈ E and g^{2^{k−1}} ∉ E. If g^{2^k} = 1, then g^{2^{k−1}} would
be an involution outside E = Ω₁(G), impossible. So g^{2^k} ∈ E∖{1} and |g| = 2^{k+1}.
(v): let Ã be the preimage of A. Ã/E = A is elementary abelian, so Ã² ≤ E and Ã′ ≤ E ≤ Z(Ã); Ã has class ≤ 2.
For a ∈ Ã, e ∈ E: (ae)² = a²e² = a², and (ab)² = a²b²[b,a] with [b,a] ∈ E bilinear on A. Thus q_A(aE) := a² is a
well-defined quadratic map A → E with polar form the commutator pairing. If q_A(aE) = 0 with aE ≠ 0 then a ∉ E
is an involution, impossible. So the r coordinate forms of q_A have no common non-trivial zero on A ≅ F₂^n, and
Chevalley–Warning (Σ deg = 2r < n would force one) gives n ≤ 2r.
(vi): let Q̃ be the preimage of Q, a central extension 1 → E → Q̃ → Q → 1. The five-term exact sequence
H₂(Q̃) → H₂(Q) → E → Q̃^{ab} → Q^{ab} → 0 gives E ∩ Q̃′ = image of H₂(Q) = 0. Hence Q̃′ ≅ Q′; if Q′ ≠ 1 then the
non-trivial 2-group Q̃′ contains an involution outside E, impossible. Generalised quaternion groups have trivial
Schur multiplier.
(vii): if r = 1, G has a unique involution, so G is cyclic or generalised quaternion and d(G) ≤ 2 = 2r. So r ≥ 2.
Since E ≤ Φ(G), |Φ(G)| ≥ 2^r; if Φ(G) = E then Φ(G) is central elementary abelian and Theorem A (Remark) gives
d ≤ 2r. So |Φ(G)| ≥ 2^{r+1} and |G| = 2^{d}|Φ(G)| ≥ 2^{3r+2} ≥ 2⁸. ∎

Corollary. If a counterexample exists, a counterexample of minimal order has |G| ≥ 2⁸ and is a central
extension of H = G/E with d(H) = 2r + 1, |H| = |G|/2^r, in which (by (iv)) no involution of H lifts to an
involution. Conversely, a central extension G of a 2-group H by E = C₂^r with E ≤ Φ(G) and no involution outside
E would be a counterexample as soon as d(H) > 2r.

## Theorem C (small orders): no counterexample of order ≤ 2¹¹
By Theorem B(vii), a minimal counterexample G has |G| = 2^{2r+1}·|Φ(G)| with |Φ(G)| ≥ 2^{r+1} and r ≥ 2:
* r = 2: |G| ≥ 2⁸; r = 3: |G| ≥ 2¹¹; r = 4: |G| ≥ 2¹⁴.
* |G| = 2⁸ (r = 2, |Φ| = 8): excluded by the exhaustive sweep of all groups of order 256 (`check.g`, `log.txt`).
* |G| = 2⁹, 2¹⁰ (r = 2, |Φ(G)| = 16, 32; H = G/E of order 2⁷, 2⁸ with d(H) = 5) and |G| = 2¹¹ (r = 3,
  |Φ(G)| = 16, H of order 2⁸ with d(H) = 7; or r = 2, H of order 2⁹ with d(H) = 5): see the cohomological
  analysis below (`ext.g`, `ext2.g`, `ext3.g`, logs `r256log*`, `r128log*`, `r256r2log_*`, `r512log_*`).

### The cohomological analysis
Fix r and a candidate quotient H (a group of order 2^{d}·|Φ(H)| with d(H) = 2r + 1, taken from the SmallGroups
library). A minimal counterexample with G/E ≅ H is a central extension of H by E = F₂^r, given by r classes
α₁,…,α_r ∈ H²(H, F₂). For a 2-cocycle c with values in F₂ and an involution h of H let ℓ_h(c) ∈ F₂ be the square
of a lift of h in the extension defined by c (well defined: lifts differ by central elements of order 2). ℓ_h is
linear in c and vanishes on coboundaries (a split extension is a direct product). In the extension G defined by
(α₁,…,α_r) the square of a lift of h is (ℓ_h(α₁),…,ℓ_h(α_r)) ∈ E. Hence Theorem B(iv) says:

  (*) for every involution h of H, (ℓ_h(α₁),…,ℓ_h(α_r)) ≠ 0.

Filters used, in this order:
* (F1) H contains an elementary abelian subgroup of rank 2r + 1 ⇒ excluded (Theorem B(v)).
* (F2) some maximal subgroup M̄ of H has Φ(M̄) ≠ Φ(H) ⇒ excluded (Theorem B(iii)).
* (F3) some involution h has ℓ_h = 0 on all cocycles ⇒ excluded ((*) fails for every choice of classes).
* survivors: the functionals ℓ_h are exported and a search for classes satisfying (*) is run (`coverr.c`).

ℓ_h is computed with GAP: `TwoCocycles(H, F₂)`, `Extension(H, F₂, c)` for each basis cocycle c, and the square of
the lift of h in that pc group. Sanity checks: ℓ_h vanishes on `TwoCoboundaries`, and for H = Q₈ × C₂⁵ the central
involution of Q₈ has ℓ = 0, as forced by B(vi) (Q₈ has trivial multiplier).

Results.
* r = 3, |G| = 2¹¹, H of order 256 with d(H) = 7 (10 groups, ids 56082–56091): C₄ × C₂⁶ and D₈ × C₂⁵ fail (F1),
  the other eight fail (F3) (`r256.g`). So there is no counterexample of order 2¹¹ with r = 3.
* r = 2, |G| = 2⁹, H of order 128 with d(H) = 5 (169 groups, ids 2150–2318): 40 fail (F2), 98 fail (F3), 31 fail (F1);
  no survivor (`r128log.txt`). So there is no counterexample of order 2⁹.
* r = 2, |G| = 2¹⁰, H of order 256 with d(H) = 5 (28653 groups, ids 26973–55625): 7043 fail (F2), 21610 fail (F3);
  no survivor (`r256r2log_*.txt`). So there is no counterexample of order 2¹⁰ (r = 3 needs |G| ≥ 2¹¹, r ≥ 4 needs |G| ≥ 2¹⁴).
* r = 2, |G| = 2¹¹, H of order 512 with d(H) = 5: not analysed (≈ 7·10⁶ groups). For r = 2 the answer is known
  from the classification of 2-groups with exactly three involutions (M. Konvisser, Math. Z. 130 (1973), 19–30;
  Z. Janko, J. Algebra 291 (2005), 505–533); we have not re-derived d ≤ 4 from those classifications here, so the
  claim "no counterexample of order 2¹¹" rests on that literature for the case r = 2.
* r = 3, |G| = 2¹², H of order 512 with d(H) = 7 (1139 groups, ids 10493062–10494200): all fail (F1/F2/F3, see the
  counts in `r512log_*.txt`); no survivor. So there is no counterexample of order 2¹² with r = 3 (r = 2 would need
  H of order 2¹⁰, r ≥ 4 needs |G| ≥ 2¹⁴).

(Where a survivor is reported, the random search in `coverr.c` for classes satisfying (*) decides existence; a
found solution would be turned into an explicit group and verified directly in GAP.)
