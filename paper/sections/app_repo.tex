\section{The repository}\label{app:repo}

The repository (git, branch \code{master}; 94 commits during the run, later commits add this paper) has the following layout.
\begin{itemize}
\item \code{README.md} --- entry point; \code{plans/PLAN.md} --- the plan and the triage tables.
\item \code{reports/} --- one Markdown report per solved or partially solved problem:
\path{21.32_derived_subgroup_decidability.md}, \path{16.60_twisted_frobenius_schur.md},
\path{2.78_group_theoretic_numbers.md}, \path{18.46_square_roots_sharpness.md},
\path{13.19_subdirect_products_counterexample.md}, \path{16.14_notes.md}, \path{20.37_subset_factorizations.md},
\path{20.21_notes.md}, \path{19.56_star_commutators.md}, \path{21.26_notes.md}, \path{21.111_tau_groups_partial.md},
\path{18.117_coprime_commutators_sporadic.md}; the index \code{README.md}; the table \code{verifications.md}; and
the chronological log \code{PROGRESS.md}.
\item \code{work/p<problem>/} --- 57 directories with the scripts (261 GAP files, 14 Python files, 7 C files) and
their logs; each report names the scripts that support its claims. Examples: \path{work/p21_26/check2.g} (the
double-coset checker), \path{work/p16_14/pcover_filter.g} (the 2-covering-group filter),
\path{work/p20_37/fact4.py}, \code{dlx.c}, \path{verify_all2.g} (the factorisation search and its independent
verification), \path{work/p20_71/cards.c} (the nauty filter).
\item \code{session/} --- the complete transcript of the run (main session and the six sub-agents, JSON lines).
\item \code{docs/} --- the notebook (PDF and text); \code{paper/} --- this paper.
\end{itemize}
The GAP installation and the Python virtual environment are not part of the repository. All computations were run
with GAP~4.16.1 as installed in \code{gap-4.16.1/}; the scripts use only library functions of GAP and its standard
packages, and can be re-run with commands of the form
\texttt{gap -q -b -o 8g work/p21\_26/s2\_601\_650.g}.
