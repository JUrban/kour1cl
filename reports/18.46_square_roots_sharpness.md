# Problem 18.46 (Ant. A. Klyachko) — the bound |H| ≤ 2|G|² is sharp

**Problem 18.46.** Every finite group G can be embedded in a group H in such a way that every element of G is
a square of an element of H; H can be chosen with |H| ≤ 2|G|². Is this estimate sharp? (It is known that
the best possible estimate cannot be better than |H| ≤ |G|², Baranov–Klyachko 2012.)

**Answer: Yes, the estimate is sharp.** For G = D₈ (dihedral of order 8):

> **Theorem.** Let H be a finite group containing a subgroup D ≅ D₈ such that every element of D is a square in H.
> Then |H| ≥ 128 = 2|D₈|². The bound is attained: in the wreath product H = D₈ ≀ C₂ = (D₈ × D₈) ⋊ ⟨σ⟩ (order 128),
> the diagonal subgroup {(g,g)} ≅ D₈ consists of squares, since ((g,1)σ)² = (g,1)·(1,g) = (g,g).

Hence no bound of the form |H| ≤ c·|G|² with c < 2 holds for all G, i.e. Klyachko's estimate |H| ≤ 2|G|² is
best possible in general. (The same wreath-product construction is the source of the general bound 2|G|².)

## Proof of the lower bound (exhaustive verification, two independent computations)

If |H| < 128 and D₈ ≤ H then 8 | |H|, so |H| ∈ {8, 16, …, 120}. All groups of these orders are contained in the
GAP SmallGroups library (complete for all orders ≤ 2000). Two independent GAP computations
(`work/p18_46/check.g`, `work/p18_46/verify_d8.g`) show that no group H of order 8, 16, …, 120 has a subgroup
S ≅ D₈ with S ⊆ {h² : h ∈ H}:

* `check.g` uses `IsomorphicSubgroups(H, D8)` (all embeddings up to conjugacy; the property "image consists of
  squares" is conjugation-invariant) and finds the minimal order 128 (first example SmallGroup(128,134)).
* `verify_d8.g` uses the full subgroup lattice: for every class representative S of subgroups of order 8 with
  IdGroup(S) = IdGroup(D₈) it tests S ⊆ Sq(H) := {h² : h ∈ H}; the list of groups of order < 128 with such an S is
  empty (log `verify_d8_log.txt`), and D₈ ≀ C₂ = SmallGroup(128,928) does contain such an S. Exactly 14 of the
  2328 groups of order 128 contain a subgroup ≅ D₈ consisting of squares (ids 134, 136, 144, 146, …, 928).

Both computations only use: element squaring, subgroup enumeration and group identification for groups of
order ≤ 128, which are standard and reliable in GAP 4.16.
