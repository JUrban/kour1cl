# Problem 20.37 (Hooshmand) — subset factorizations G = AB with prescribed |A|, |B|

**Problem.** Is it true that for every finite group G and every factorization |G| = ab there are subsets
A, B ⊆ G with |A| = a, |B| = b and G = AB?
Known (comment of 2025 in the Notebook): a minimal counterexample is a non-abelian simple group without
subgroups of prime index.

**Status.** Not settled in general. We (1) determine, for every non-abelian simple group of order ≤ 10⁶, which
factor sizes are *chain-achievable* (obtainable from subgroup chains and transversals — the "obvious" method),
(2) show that for many simple groups some factor sizes are not chain-achievable (the first is PSL(2,8), orders
12·42 = 21·24 = 504), and (3) realise every such factor size for all simple groups of order ≤ N (N reported below)
by an explicit new construction (a union of cosets of a subgroup on one side, and an exact cover of the coset
space on the other side), with the found sets A, B verified independently in GAP (`work/p20_37/verify.g`,
solution files `sol_<|G|>.txt`).

## 1. Elementary facts
(a) G = AB with |A||B| = |G| iff all products ab (a ∈ A, b ∈ B) are distinct, iff A⁻¹A ∩ BB⁻¹ = {1}.
(b) If G = AB then G = B⁻¹A⁻¹; so the set L(G) := {|A| : G = AB for some A, B} is closed under a ↦ |G|/a.
(c) If H ≤ G, T a left transversal and T′ a right transversal of H, then G = TH = HT′. Hence if H = A₁B₁ then
    G = (TA₁)B₁ = A₁(B₁T′), so L(G) ⊇ L(H) ∪ |G:H|·L(H).
Define the *chain-achievable* set L′(G) as the smallest set containing 1, |G| and closed under (b), (c) (with
L′(H) in place of L(H), over all subgroups H — it suffices to use maximal subgroups recursively). Then
L′(G) ⊆ L(G). `work/p20_37/chain.g` computes L′(G) from the maximal subgroup lattice (memoised by IdGroup).

## 3. The coset-union construction and a general theorem for k = 2
**Lemma 1.** Let H ≤ G, |H| = h, and x₁ = 1, x₂, …, x_k ∈ G with the right cosets Hx₁, …, Hx_k distinct. Put
A := Hx₁ ∪ … ∪ Hx_k (|A| = kh). Suppose B ⊆ G is such that the k-sets {Hx₁b, …, Hx_kb} (b ∈ B) are pairwise disjoint
and cover H\G (an exact cover of the right coset space by these k-sets; then |B| = |G|/(kh)). Then G = AB.
*Proof.* AB = ⋃_{i,b} Hx_ib is the union of the cosets Hx_ib, which are all the |G:H| right cosets, each exactly once;
so AB = G and |A||B| = |G|. ∎

**Theorem 1.** Let H ≤ K ≤ G with |K:H| even, and suppose K = ⟨H, x⟩ for some x ∈ K. Then 2|H| ∈ L(K) ⊆ L(G):
there is B ⊆ K, |B| = |K|/(2|H|), with K = (H ∪ Hx)B.
*Proof.* Let Γ be the simple graph with vertex set H\K (right cosets of H in K) and an edge {Hb, Hxb} for every
b ∈ K with Hb ≠ Hxb. K acts on H\K by right multiplication, Hb ↦ Hbg; this maps the edge {Hb, Hxb} to {Hbg, Hxbg},
so K acts on Γ by automorphisms, transitively on the vertices: Γ is vertex-transitive. The neighbours of Hb are the
cosets Hx^{±1}hb (h ∈ H), so the vertices reachable from Hb are the cosets Hwb with w ∈ ⟨H, x⟩ = K, i.e. all of
them: Γ is connected. Now use the Gallai–Edmonds structure theorem: let D be the set of vertices missed by at
least one maximum matching of Γ. D is invariant under Aut(Γ), hence D = ∅ or D = V(Γ). If D = V(Γ), the theorem
says that every component of Γ[D] = Γ is factor-critical, so the connected graph Γ has an odd number of vertices,
contradicting |K:H| even. Hence D = ∅, i.e. every vertex is covered by every maximum matching: Γ has a perfect
matching M. Choosing for each matching edge e ∈ M an element b_e ∈ K with e = {Hb_e, Hxb_e} and putting
B := {b_e : e ∈ M}, the 2-sets {Hb, Hxb} (b ∈ B) partition H\K, and Lemma 1 (applied in K, with k = 2) gives
K = (H ∪ Hx)B. Finally L(K) ⊆ L(G) by fact (c) of §1. ∎

(The step "connected vertex-transitive graph of even order has a perfect matching" is classical; the argument
via Gallai–Edmonds is included for completeness. For k ≥ 3 the analogous statement — a perfect matching in the
vertex-transitive k-uniform hypergraph with hyperedges {Hx₁b, …, Hx_kb} — has no general proof here; those cases
are settled by computation: a SAT solver (CaDiCaL via python-sat) finds an exact cover, and random choices of
x₂, …, x_k succeed almost immediately in all cases tried.)

Example: G = PSL(2,8), H ≅ S₃ (order 6), any x with ⟨H, x⟩ = G: Theorem 1 gives 12 ∈ L(G), which is not
chain-achievable. Theorem 1 is applied recursively (also inside subgroups) in `chain2.g`; the sizes still missing
afterwards for simple groups of order ≤ 10⁶ are listed in `run3_log.txt` and handled by the exact-cover search.
