# Problem 16.60 (D. MacHale) — the inequality T(G) ≥ |S_α| holds for every automorphism α

**Problem 16.60.** For a finite group G let T(G) = Σ_{χ ∈ Irr(G)} χ(1) be the sum of the degrees of the
irreducible complex representations of G. For α ∈ Aut(G) let S_α = {g ∈ G | α(g) = g⁻¹}. Is it true that
T(G) ≥ |S_α| for all α ∈ Aut(G)?

**Answer: Yes.** More precisely, for every finite group G and every α ∈ Aut(G),

  |S_α| = Σ_{θ ∈ Irr(C)} ε_α(θ) θ(1) ≤ T(C) ≤ T(G),   where C = C_G(α²) = {g ∈ G : α²(g) = g},

and ε_α(θ) ∈ {1, 0, −1} is the twisted Frobenius–Schur indicator of θ with respect to the involutory
automorphism α|_C of C. (For α = id the statement is the classical inequality T(G) ≥ 1 + #{involutions}, and for
α of order ≤ 2 it is the Kawanaka–Matsuyama twisted Frobenius–Schur theorem; the point of the general case is the
reduction to the involutory case via C_G(α²) together with the monotonicity of T.) The proof below is
self-contained.

## Proof

**Step 1 (reduction to an involutory automorphism).** Let α ∈ Aut(G) and put C := C_G(α²) = {g : α²(g) = g}.
If g ∈ S_α, then α²(g) = α(g⁻¹) = α(g)⁻¹ = g, so S_α ⊆ C. Since α commutes with α², α(C) = C, and
σ := α|_C ∈ Aut(C) satisfies σ² = α²|_C = id_C. Clearly S_α = {g ∈ C : σ(g) = g⁻¹} =: S_σ(C).
Hence it suffices to prove:

  (A) for every finite group C and every σ ∈ Aut(C) with σ² = 1: |S_σ(C)| ≤ T(C);
  (B) for every subgroup C ≤ G: T(C) ≤ T(G).

**Step 2 (proof of (B)).** For θ ∈ Irr(C) the induced character θ^G is a non-zero character, so
m(θ) := Σ_{χ ∈ Irr(G)} ⟨χ, θ^G⟩ ≥ 1. By Frobenius reciprocity,
  T(G) = Σ_χ χ(1) = Σ_χ Σ_θ ⟨χ_C, θ⟩ θ(1) = Σ_θ θ(1) m(θ) ≥ Σ_θ θ(1) = T(C).

**Step 3 (proof of (A): twisted Frobenius–Schur indicators).** Let σ ∈ Aut(C), σ² = 1. For θ ∈ Irr(C) put
  ε_σ(θ) := (1/|C|) Σ_{g ∈ C} θ(g σ(g)).

(i) Counting. By the second orthogonality relation Σ_{θ ∈ Irr(C)} θ(1) θ(x) = |C| · [x = 1], we get
  Σ_θ ε_σ(θ) θ(1) = (1/|C|) Σ_{g} Σ_θ θ(1) θ(gσ(g)) = #{g ∈ C : g σ(g) = 1} = #{g : σ(g) = g⁻¹} = |S_σ(C)|.

(ii) ε_σ(θ) ∈ {1, 0, −1}. Let ρ : C → GL(V) afford θ and let ρ^σ := ρ ∘ σ (an irreducible representation
affording θ^σ := θ ∘ σ). For linear maps A, B on V one has tr(AB) = tr(τ ∘ (A ⊗ B)), where τ : V ⊗ V → V ⊗ V is
the flip v ⊗ w ↦ w ⊗ v. Hence
  ε_σ(θ) = (1/|C|) Σ_g tr( τ ∘ (ρ(g) ⊗ ρ^σ(g)) ) = tr( τ ∘ P ),
where P = (1/|C|) Σ_g (ρ ⊗ ρ^σ)(g) is the projection of V ⊗ V onto the subspace W := (V ⊗ V)^C of
invariants of the representation ρ ⊗ ρ^σ. Since σ² = 1 we have (ρ^σ)^σ = ρ, and therefore
  τ ∘ (ρ ⊗ ρ^σ)(g) = (ρ^σ ⊗ ρ)(g) ∘ τ = (ρ ⊗ ρ^σ)(σ(g)) ∘ τ  for all g ∈ C.
Consequently τ maps W into itself (if w ∈ W then (ρ⊗ρ^σ)(g)τw = τ(ρ⊗ρ^σ)(σ⁻¹g)w = τw), and τ∘P = τ|_W ∘ P,
so ε_σ(θ) = tr(τ|_W). Now τ|_W is an involution of W, hence tr(τ|_W) ∈ Z and |tr(τ|_W)| ≤ dim W. Finally
  dim W = dim Hom_C(V^*, V^σ) = ⟨θ̄, θ^σ⟩ ≤ 1
because θ̄ and θ^σ are irreducible. Thus ε_σ(θ) ∈ {1, 0, −1} (and ε_σ(θ) = 0 unless θ^σ = θ̄).

(iii) From (i) and (ii): |S_σ(C)| = Σ_θ ε_σ(θ) θ(1) ≤ Σ_θ θ(1) = T(C). This proves (A).

**Step 4.** Combining Steps 1–3: |S_α| = |S_σ(C)| ≤ T(C) ≤ T(G). ∎

## Remarks

* Equality analysis: |S_α| = T(G) forces T(C) = T(G) (so every θ ∈ Irr(C) induces irreducibly, i.e. C = G
  or … in fact m(θ) = 1 for all θ, which forces C = G since T(G) ≥ Σ_θ θ(1)·|G:C|_{…}? no — simply: m(θ)=1
  for all θ means |G| = Σ_χ χ(1)² ≥ Σ_θ θ(1)·(θ^G(1)) = |G:C|·|C| with equality only if every χ is induced
  from C with multiplicity one; the classical case α = id shows equality can hold (e.g. abelian G of exponent 2))
  and ε_σ(θ) = 1 for all θ ∈ Irr(C). We do not pursue this.
* The reduction in Step 1 is the only new ingredient; Steps 2 and 3 are standard (Step 3 is the twisted
  Frobenius–Schur theorem of N. Kawanaka and H. Matsuyama, Hokkaido Math. J. 19 (1990), 213–225, whose short
  proof we included for completeness).
* A numerical sanity check of the inequality for all groups of order ≤ 200 and all automorphisms (up to
  conjugacy in Aut G) is in `work/p16_60/` (script `check.g`, log `log.txt`).
