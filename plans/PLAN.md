# Plan (written 2026-09-13 ~08:50 UTC)

Deadline: 2026-09-15 08:03 UTC.

## Strategy
1. Triage all ~2300 open problems for those attackable by (a) finite computer search producing
   a counterexample / explicit object, or (b) a short rigorous argument possibly aided by computation.
   Five triage agents scan issues 1–20; I read the 21st issue (new problems) myself.
2. Launch cheap exhaustive searches immediately on the most concrete problems (GAP libraries:
   SmallGroups, TransitiveGroups, PrimitiveGroups, simple groups, skew braces).
3. For anything that yields a counterexample: verify independently (second script / second method),
   write a rigorous report with reproducible scripts, commit.
4. For problems where searches find nothing: record verified ranges (partial results) in reports.
