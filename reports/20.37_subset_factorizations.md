# Problem 20.37 (Hooshmand) — subset factorizations G = AB with prescribed |A|, |B|

**Problem.** Is it true that for every finite group G and every factorization |G| = ab there are subsets
A, B ⊆ G with |A| = a, |B| = b and G = AB?
Known (comment of 2025 in the Notebook): a minimal counterexample is a non-abelian simple group without
subgroups of prime index.

**Status.** Not settled in general. We (1) determine, for every non-abelian simple group of order ≤ 10⁶, which
factor sizes are *chain-achievable* (obtainable from subgroup chains and transversals — the "obvious" method),
(2) show that for many simple groups some factor sizes are not chain-achievable (the first is PSL(2,8), orders
12·42 = 21·24 = 504), and (3) realise every such factor size for all simple groups of order ≤ N (N reported below)
by an explicit new construction (a union of cosets of a subgroup on one side, and an exact cover of the coset
space on the other side), with the found sets A, B verified independently in GAP (`work/p20_37/verify.g`,
solution files `sol_<|G|>.txt`).

## 1. Elementary facts
(a) G = AB with |A||B| = |G| iff all products ab (a ∈ A, b ∈ B) are distinct, iff A⁻¹A ∩ BB⁻¹ = {1}.
(b) If G = AB then G = B⁻¹A⁻¹; so the set L(G) := {|A| : G = AB for some A, B} is closed under a ↦ |G|/a.
(c) If H ≤ G, T a left transversal and T′ a right transversal of H, then G = TH = HT′. Hence if H = A₁B₁ then
    G = (TA₁)B₁ = A₁(B₁T′), so L(G) ⊇ L(H) ∪ |G:H|·L(H).
Define the *chain-achievable* set L′(G) as the smallest set containing 1, |G| and closed under (b), (c) (with
L′(H) in place of L(H), over all subgroups H — it suffices to use maximal subgroups recursively). Then
L′(G) ⊆ L(G). `work/p20_37/chain.g` computes L′(G) from the maximal subgroup lattice (memoised by IdGroup).

## 3. The coset-union construction
**Lemma.** Let H ≤ G, |H| = h, and x₁ = 1, x₂, …, x_k ∈ G. Put A := Hx₁ ∪ … ∪ Hx_k (assume the cosets are distinct,
so |A| = kh). Suppose B ⊆ G is such that the k-sets {Hx₁b, …, Hx_kb} (b ∈ B) are pairwise disjoint and cover the set
H\G of right cosets (an exact cover of H\G by these k-sets; then |B| = |G|/(kh)). Then G = AB.
*Proof.* AB = ⋃_{i,b} Hx_ib is the union of the cosets Hx_ib, which are all the |G:H| right cosets, each once; so
AB = G and |A||B| = |G|. ∎
For k = 2 the exact cover is a perfect matching in the multigraph on H\G with edges {Hb, Hxb} (b ∈ G); for k ≥ 3
it is an exact cover problem, solved by a SAT solver (CaDiCaL via python-sat). Random choices of x₂, …, x_k
succeed almost immediately in all cases tried. (This construction is not chain-achievable in general because the
transversal XB of H is not built from subgroups.)
