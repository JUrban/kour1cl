# Problem 18.117 (P. Shumyatsky) — verification for sporadic groups

**Problem.** Is every element of a non-abelian finite simple group a commutator [x,y] of two elements of
coprime orders? (Known for A_n and PSL(2,q).)

**Result (computational).** For each of the following sporadic simple groups, every conjugacy class contains a
commutator [x,y] with gcd(|x|,|y|) = 1 (so the answer is *yes* for these groups):

  M₁₁, M₁₂, M₂₂, M₂₃, M₂₄, J₁, J₂, HS, J₃, McL, He   (work/p18_117/log.txt),

and (targeted search, see below) further groups listed in `work/p18_117/log2.txt` as they complete.

**Method.** `work/p18_117/coprime.g`: for a permutation group G, draw random pairs (x,y) with gcd(|x|,|y|) = 1,
compute [x,y] and record its conjugacy class (membership test in the class list); stop when all classes are
hit. Every hit is a certificate (an explicit pair), so the positive conclusions are rigorous; only the failure
to hit a class within the budget would be inconclusive. For classes with large centralisers (rarely hit at
random) `coprime2.g` uses a targeted search: for g in the class, find x with xg conjugate to x, take y₀ with
x^{y₀} = xg and search the coset C_G(x)·y₀ for an element y of order coprime to |x| (then [x,y] = g).
The groups were taken from the AtlasRep package (permutation representations).
